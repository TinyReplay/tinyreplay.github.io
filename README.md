# Игры детства — отдельный каталог для GitHub Pages

Распакуйте содержимое архива в корень ОТДЕЛЬНОГО репозитория и отправьте через Git.
В Settings → Pages выберите Deploy from a branch, свою ветку и / (root).
Файл index.html должен лежать в корне, не внутри дополнительной папки.

Здесь только главная страница: движок и файлы игры не включены.
Tank-o-Box ведёт на https://gorbachevvv.github.io/tank-o-box-remastered/.
Это существующий сайт игры; когда разместите там страницу с описанием, ссылка
останется той же. Если адрес игры изменится, исправьте href в page/games.json.

Добавление игры: положите квадратную обложку в page/media/ и добавьте объект
в массив page/games.json. Образец:

    { "title": "Название", "year": 2000, "genre": "Аркада",
      "cover": "./page/media/cover.webp", "href": "https://USER.github.io/GAME/" }

Пути обложек относительны главной странице. href — адрес страницы игры в её
репозитории. Между объектами ставьте запятые; после последнего — не нужно.
Исходный проект может пересобрать этот каталог командой npm run build:catalogue.
Для самого хостинга Node.js не нужен. Локально открывайте через HTTP, не file://.
